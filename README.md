# Betriebssysteme – Praktikum

Beispielprogramme und Dateien für das Praktikum der Lehrveranstaltung **Betriebssysteme**
(Bachelor Angewandte Informatik, Hochschule Fulda, Prof. Dr. Jonas Posner).

## Herkunft

Die Programme stammen von Sven Reißmann (Hochschule Fulda), der sie für seine Lehrveranstaltung
*Betriebssysteme* geschrieben hat. Sie sind für die Lehre an der Hochschule Fulda gedacht.
